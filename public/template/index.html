Cara memakainya

1

Download

Klik tombol download. File .xlsx langsung tersimpan, tanpa perlu daftar atau isi email.

2

Hapus data contoh

Setiap template berisi data CONTOH supaya dashboard terlihat hidup. Ganti dengan data Anda sendiri.

3

Pantau dashboard

Rumus dan grafik menyesuaikan otomatis. Mau pakai Google Sheets? Upload filenya ke Google Drive.

Semua angka di dalam template adalah CONTOH, bukan data nyata. Penjelasan konsepnya ada di artikel reorder point, safety stock, dan stock opname vs cycle count. Butuh hitung muatan kontainer? Coba kalkulator kubikasi.
