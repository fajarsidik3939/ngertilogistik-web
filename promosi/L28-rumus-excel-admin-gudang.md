## 2. Carousel Instagram / LinkedIn (7 slide)

1. **3 rumus Excel yang paling sering dipakai admin gudang.**
2. SUMIF: menjumlahkan angka dengan syarat. Contoh: total barang keluar untuk satu SKU dari ratusan baris transaksi.
3. Contoh: SKU-A01 keluar 12, 8, dan 20. `=SUMIF(B2:B6,"SKU-A01",D2:D6)` hasilnya 40. (Data contoh, fiktif.)
4. VLOOKUP: cari data dari tabel master. Kode harus di kolom paling kiri, dan argumen terakhir isi FALSE supaya mencari yang sama persis.
5. XLOOKUP: lebih fleksibel, kolom hasil boleh di kiri atau kanan, dan bawaannya sudah mencari yang sama persis. Tidak tersedia di Excel 2016 dan 2019.
6. Pivot table: rangkum ribuan baris jadi rekap per kategori atau per minggu. Ingat: Refresh setiap kali data berubah.
7. Mulai dari satu rumus, pakai data kerja sendiri. Contoh lengkap: ngertilogistik.web.id/blog/rumus-excel-admin-gudang

## 3. Post LinkedIn

Banyak admin gudang baru merasa harus menghafal puluhan rumus Excel. Padahal untuk laporan stok harian, tiga sudah cukup.

2. VLOOKUP atau XLOOKUP, untuk mencari data dari tabel lain. Misalnya lokasi rak berdasarkan kode SKU. Kalau pakai VLOOKUP, biasakan isi FALSE di argumen terakhir supaya hasilnya tidak meleset diam-diam.
3. Pivot table, untuk merangkum ribuan baris jadi rekap per kategori atau per minggu. Dan ingat, pivot table tidak memperbarui dirinya sendiri: Refresh setiap kali data berubah.

## 4. Post grup Facebook / komunitas

Teman-teman admin gudang, ini tiga rumus Excel yang paling sering dipakai untuk laporan stok, beserta jebakannya:

1. **SUMIF**: menjumlah dengan syarat. Contoh `=SUMIF(B2:B6,"SKU-A01",D2:D6)` menjumlah kolom D hanya untuk baris yang kodenya SKU-A01.
2. **VLOOKUP**: cari nama barang atau lokasi rak dari kode SKU. Jebakan: argumen terakhir wajib FALSE, dan kode harus ada di kolom paling kiri tabel.
3. **XLOOKUP**: versi yang lebih fleksibel, tapi tidak ada di Excel 2016 dan 2019.
4. **Pivot table**: rekap per kategori atau per minggu. Jebakan: tidak berubah sendiri, harus di-Refresh.

Tips kecil: kalau Excel menolak rumus dengan tanda koma, coba ganti dengan titik koma. Pemisahnya mengikuti pengaturan regional komputer.

## 7. Jawaban forum / tanya-jawab

**Pertanyaan:** Rumus Excel apa saja yang perlu dikuasai untuk melamar jadi admin gudang?

**Jawaban:**
Untuk laporan stok harian, tiga rumus ini paling sering dipakai.

Pertama, SUMIF, untuk menjumlahkan angka dengan syarat. Misalnya total barang keluar untuk satu kode SKU dari ratusan baris transaksi. Kalau syaratnya lebih dari satu, misalnya SKU dan bulan tertentu, pakai SUMIFS.

Kedua, VLOOKUP atau XLOOKUP, untuk mencari data dari tabel lain, misalnya nama barang atau lokasi rak berdasarkan kode SKU. Di VLOOKUP, kode harus ada di kolom paling kiri tabel dan argumen terakhir diisi FALSE supaya mencari yang sama persis. XLOOKUP lebih fleksibel, tapi tidak tersedia di Excel 2016 dan 2019.

Ketiga, pivot table, untuk merangkum ribuan baris jadi rekap per kategori atau per minggu. Pivot table tidak memperbarui dirinya sendiri, jadi klik Refresh setiap kali data berubah.

Cara belajar paling cepat: satu rumus per minggu, langsung pakai data nyata atau data latihan yang mirip pekerjaan gudang.
